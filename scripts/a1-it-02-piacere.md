# A1 Audio Lesson — Sample Script (Italian)

**Title:** "Piacere!" — Introducing yourself
**Level:** A1 (total beginner)
**Runtime target:** ~4 minutes
**Hosts:** Clara (IT/EN bilingual) & Max (IT/EN bilingual)
**Scenario voices:** Marco (man), Giulia (woman) — native Italian speakers, meeting for the first time

**A1 skill focus:** introducing yourself and asking someone's name — the second thing every
visitor needs after ordering a coffee. Three repertoire phrases: "Mi chiamo...", "Piacere,"
and "Io sono...".

**Pedagogy note:** same policy as episode 1 — no proactive pronunciation coaching, full
repertoire phrases only, more repetition than a B1 script needs. See the top-level README's
pedagogy section.

## Production notes
- **Marco / Giulia voices**: reuse the native Italian voices from episode 1's "hear it around
  town" montage (Stefano Ca and Carlotta), recast as named characters here — same actors,
  different scenario, exactly like a recurring bit-part voice cast in audio drama.
- **All hosts' voices verified up front**: Max uses Vittorio (en+it verified) from the start,
  not Chris — this episode was scripted after the episode 1 fix, so the verified_languages
  check happened before writing dialogue, not after finding a bug.
- **Scope**: three repertoire phrases (mi chiamo / piacere / io sono) built directly from the
  demo dialogue, same shape as episode 1.
- **No proactive pronunciation coaching**, consistent with the standing policy.
- **Cue order**: prompt → SPEAKER SFX → pause (attempt) → CORRECT SFX → answer, written this
  way from the start — episode 1's first draft had the answer play before SPEAKER SFX, giving
  it away before the listener could try. See episode 1's production notes for the fix.
