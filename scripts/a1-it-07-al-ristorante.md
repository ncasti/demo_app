# A1 Audio Lesson — Sample Script (Italian)

**Title:** "Al ristorante" — At the restaurant
**Level:** A1 (total beginner)
**Runtime target:** ~4 minutes
**Hosts:** Clara (IT/EN bilingual) & Max (IT/EN bilingual)
**Scenario voices:** Cameriere (waiter, man), Cliente (woman) — native Italian speakers

**A1 skill focus:** getting a table, ordering, and asking for the check — a complete
restaurant visit. Three repertoire phrases: "Un tavolo per due, per favore," "Vorrei la
pasta," and "Il conto, per favore."

**Pedagogy note:** same standing policy as prior episodes — no proactive pronunciation
coaching, full repertoire phrases only.

## Production notes
- **Cameriere / Cliente voices**: Cameriere reuses the Alessandro actor (Barista/Venditore in
  earlier episodes), Cliente reuses Carla — same recurring native cast, new scenario.
- **Cue order**: prompt → SPEAKER SFX → pause (attempt) → CORRECT SFX → answer, throughout.
- **Scope**: three repertoire phrases (un tavolo per due / vorrei la pasta / il conto per
  favore) built directly from the demo dialogue. "Vorrei" is a deliberate callback to episode
  3's market scenario — same verb, new domain, spaced repetition by design.
