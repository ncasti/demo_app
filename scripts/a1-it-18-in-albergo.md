# A1 Audio Lesson — Sample Script (Italian)

**Title:** "In albergo" — Checking into a hotel
**Level:** A1 (total beginner)
**Runtime target:** ~4 minutes
**Hosts:** Clara (IT/EN bilingual) & Max (IT/EN bilingual)
**Scenario voices:** Receptionist (man) — native Italian speaker, hotel front desk

**A1 skill focus:** checking in. Three repertoire phrases: "Ho una prenotazione," "A nome...",
and "A che piano?"

**Pedagogy note:** same standing policy as prior episodes — no proactive pronunciation
coaching, full repertoire phrases only.

## Production notes
- **Receptionist's voice**: reuses the Alessandro actor — same recurring native cast, new
  scenario.
- **Cue order**: prompt → SPEAKER SFX → pause (attempt) → CORRECT SFX → answer, throughout.
- **Deliberate callback**: "A nome..." echoes the phone episode's "Sono..." — another way to
  identify yourself, different context, spaced repetition of the underlying idea.
