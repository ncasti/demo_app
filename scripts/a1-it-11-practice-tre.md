## Production notes
- **No new content**, reused native voices (Sara/Carlotta, Passante/Alessandro) — same
  recurring cast, no scene ambience, single-pass drills.
- **Cue order**: prompt → SPEAKER SFX → pause (attempt) → CORRECT SFX → answer, throughout.
- **Shorter than episodes 4/8**: only two source episodes to recap this time, so the episode
  runs leaner rather than padding it out — practice episodes should be exactly as long as the
  material warrants.
