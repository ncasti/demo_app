# A1 Audio Lesson — Sample Script (Italian)

**Title:** "Scusi, dov'è...?" — Asking for directions
**Level:** A1 (total beginner)
**Runtime target:** ~4 minutes
**Hosts:** Clara (IT/EN bilingual) & Max (IT/EN bilingual)
**Scenario voices:** Turista (woman), Passante (man) — native Italian speakers, on a street corner

**A1 skill focus:** stopping a stranger and asking where something is — the phrase every
visitor eventually needs. Three repertoire phrases: "Scusi," "Dov'è...?", and "Sempre dritto."

**Pedagogy note:** same standing policy as episodes 1–3 — no proactive pronunciation
coaching, full repertoire phrases only.

## Production notes
- **Turista / Passante voices**: reuse Carla (episode 1/3's Cliente) as Turista, and Stefano
  Ca (episode 1's Voice1 / episode 2's Marco) as Passante — same recurring native cast,
  new scenario.
- **"Sì?"** in the round-trip section is new receptive-only vocabulary (not a taught
  repertoire phrase) — included because a real passerby would actually say it; the listener
  isn't asked to produce it, only to hear it land naturally mid-exchange.
- **Scope**: three repertoire phrases (scusi / dov'è / sempre dritto) built directly from the
  demo dialogue, same shape as episodes 1–3.
- **Cue order**: prompt → SPEAKER SFX → pause (attempt) → CORRECT SFX → answer, per episode
  1's fix.
