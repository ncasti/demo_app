# A1 Audio Lesson — Sample Script (Italian)

**Title:** "Alla stazione" — At the train station
**Level:** A1 (total beginner)
**Runtime target:** ~4 minutes
**Hosts:** Clara (IT/EN bilingual) & Max (IT/EN bilingual)
**Scenario voices:** Impiegato (clerk, man) — native Italian speaker, ticket window

**A1 skill focus:** buying a train ticket. Three repertoire phrases: "Un biglietto per Roma,
per favore," "Solo andata," and "Da che binario?"

**Pedagogy note:** same standing policy as prior episodes — no proactive pronunciation
coaching, full repertoire phrases only.

## Production notes
- **Impiegato / Cliente voices**: reuse Alessandro and Carla — same recurring native cast,
  new scenario.
- **Cue order**: prompt → SPEAKER SFX → pause (attempt) → CORRECT SFX → answer, throughout.
- **Scope**: three repertoire phrases (un biglietto per / solo andata / da che binario) built
  directly from the demo dialogue. The clerk's price line ("Sono quindici euro") is left
  receptive-only, since "Quanto costa?" was already drilled in episode 3 — no need to re-teach
  it here.
